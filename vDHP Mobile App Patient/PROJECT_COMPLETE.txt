                        BEFORE PRODUCTION
================================================================================

⚠️ REQUIRED ACTIONS:

1. REPLACE VIRTUSA LOGO
   File: assets/images/virtusa-logo.png
   → Replace placeholder with actual logo PNG

2. UPDATE JWT SECRET
   File: .env
   → Change JWT_SECRET_KEY to strong random string
   → Generate: openssl rand -hex 32

3. SWITCH TO POSTGRESQL
   File: .env
   → Change DATABASE_URL to PostgreSQL connection string

4. UPDATE API URL
   File: services/api.ts
   → Change API_URL from localhost to production URL
