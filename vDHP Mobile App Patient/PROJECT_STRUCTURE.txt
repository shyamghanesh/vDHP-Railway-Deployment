DATABASE SCHEMA
===============

users
├── id (PK)
├── email (unique)
├── hashed_password
├── is_active
└── created_at

invitations
├── id (PK)
├── invitation_code (unique)
├── email
├── is_used
└── expires_at

patients
├── id (PK)
├── user_id (FK → users)
├── mrn (unique)
├── first_name
├── last_name
├── date_of_birth
├── gender
├── accessibility_font_size
└── created_at

care_plans
├── id (PK)
├── patient_id (FK → patients)
├── title
├── description
├── status
└── start_date

tasks
├── id (PK)
├── care_plan_id (FK → care_plans)
├── patient_id (FK → patients)
├── title
├── description
├── status (pending/completed)
├── priority (high/medium/low)
└── due_date

messages
├── id (PK)
├── patient_id (FK → patients)
├── sender_type
├── sender_name
├── message_text
├── is_read
└── created_at

consents
├── id (PK)
├── patient_id (FK → patients)
├── consent_type
├── is_agreed
└── agreed_at


API ENDPOINTS
=============

Authentication
├── POST /auth/validate-invitation
├── POST /auth/register
└── POST /auth/login

Patient
├── GET /patients/me
├── PUT /patients/me
├── PUT /patients/me/emergency-contact
├── PUT /patients/me/accessibility
├── POST /patients/me/consents
└── GET /patients/me/consents

Care Plans
├── GET /care-plans
├── GET /care-plans/tasks
└── PUT /care-plans/tasks/{id}/complete

Messages
├── GET /messages
└── POST /messages


USER FLOWS
==========

Registration Flow:
Welcome → Invitation → Register → Consent → Dashboard

Login Flow:
Welcome → Login → Dashboard

Dashboard Flow:
Dashboard → Tasks/Messages/Profile

Task Flow:
Tasks → View → Complete → Refresh

Message Flow:
Messages → View → Send → Refresh
