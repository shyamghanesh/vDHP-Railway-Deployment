VIRTUSA LOGO SETUP
==================

Please replace the placeholder file 'virtusa-logo.png' with the actual Virtusa logo image.

Requirements:
- Format: PNG with transparent background
- Recommended size: 600x200 pixels (3:1 aspect ratio)
- File name: virtusa-logo.png (keep this exact name)

The logo is used in:
1. Welcome screen (200x80 display size)
2. Login screen (150x50 display size)
3. Dashboard screen (150x50 display size)
4. Profile screen (150x50 display size)

After replacing the image, restart the Expo development server:
npx expo start -c
